# 사용 설명서 초안 — 설정 화면에서 뺀 설명 문구 (2026-07-31)

메인 화면 "사용 설명서 보기" 버튼은 아직 실제 페이지에 연결돼 있지 않다(UI만 있고
미연결, `MainScreen.tsx`). 그 페이지가 만들어지기 전까지, 설정 화면(`SettingsScreen.tsx`)
UI 정리 과정에서 화면 밖으로 뺀 설명 문구를 여기에 모아둔다 — 나중에 실제 사용 설명서
페이지를 만들 때 그대로 옮겨 쓰면 된다.

## 단축키

원래 설명 중 아래 두 문장을 화면에서 뺐다(핵심 규칙 한 문장만 남김):

> Shift만 걸고 문자 키를 조합하면(예: Shift+T) 그 문자 입력을 가로채 타이핑이 깨지므로
> 등록할 수 없고, 다른 단축키와 겹치거나 OS·다른 앱의 필수 단축키(Windows: Alt+F4,
> Ctrl+C 등 / macOS: Cmd+Q, Cmd+Space 등)와 겹치는 조합도 등록이 막히고 이유가
> 안내됩니다.

(참고: 이 두 제약 자체는 여전히 코드에 그대로 남아 있고, 위반 시 경고 메시지로 즉시
안내된다 — `SettingsScreen.tsx`의 단축키 녹화 로직, `shortcutMatch.ts`의
`unsafeAcceleratorReason`. 화면에서 뺀 건 사전 설명 문구뿐이다.)

## 텍스트 영역 자동 탐지

> 활성화 시 선택 모드로 전환을 하거나 선택 모드 내에서 창의 크기가 변할 때 자동으로
> 텍스트 영역을 탐지합니다. 탐지된 영역은 모드 전환 단축키로 확인할 수 있습니다.

(설정 화면에는 "노이즈가 섞일 수 있고 수동 선택으로 대체 가능"이라는 핵심 문장만 남기고,
"언제 탐지가 실행되는지"·"탐지된 영역을 어떻게 확인하는지"는 위 문장으로 여기로 옮겼다.)

## 언어 선택

> 자동: 자막/화면 텍스트로 언어를 매번 자동 판별합니다. 자막·웹 텍스트는 정확도가
> 높지만, 화면 캡처(OCR) 판별은 폰트나 레이아웃에 따라 틀리는 경우가 있어 상대적으로
> 정확도가 낮습니다. 자동 판별이 계속 틀리는 콘텐츠를 볼 때는 특정 언어를 선택해
> 판별 자체를 건너뛰고 고정하세요.

> 지원 범위는 3단계입니다 — **1단계**(영어·일본어·중국어): 언어 특화 OCR · 사전 검색 ·
> 특화된 발음 표기(히라가나/한어병음 등 그 언어 학습에 맞는 표기) · 형태소 분석기까지
> 전부 지원합니다. **2단계**: 범용 OCR과 IPA 발음, 구글 발음 검색은 되지만 사전 검색
> 기능은 없습니다 — 그중 네이버 사전 연결까지 되는 언어가 **2단계(A)**, 안 되는 언어가
> **2단계(B)**입니다(설정 화면 드롭다운 목록에서 구분).
